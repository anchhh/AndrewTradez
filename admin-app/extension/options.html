Lead Clipper — Settings

The base URL of your Estly admin-app backend. Defaults to your local dev server; change this only if you want to save leads straight to the deployed site instead (https://estly-admin.onrender.com).

The deployed site requires a login (BASIC_AUTH_USER/PASS) -- enter the same username/password here so the extension can save leads. Leave blank if you're pointed at a local backend with no auth configured (the default).
