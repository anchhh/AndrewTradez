Estly Lead Clipper — Settings

The base URL of your Estly admin-app backend. Defaults to the deployed site; change this only if you're running the backend locally instead (typically http://localhost:5050).

The deployed site requires a login (BASIC_AUTH_USER/PASS) -- enter the same username/password here so the extension can save leads. Leave blank only if you're pointed at a local backend with no auth configured.
